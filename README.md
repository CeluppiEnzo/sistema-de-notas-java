# Sistema de Notas

Projeto desenvolvido em Java para praticar os conceitos de Programação Orientada a Objetos e manipulação de listas de objetos.

## Sobre o projeto

O Sistema de Notas permite cadastrar alunos e gerenciar suas notas através de um menu no terminal.

Foi um projeto feito durante meus estudos de Java, com o objetivo de praticar principalmente classes, objetos, métodos e `ArrayList`.

## Funcionalidades

* Cadastrar aluno
* Listar alunos
* Adicionar 4 notas para um aluno
* Calcular média
* Visualizar boletim
* Remover aluno

## Conceitos praticados

* Classes e objetos
* Construtores
* Encapsulamento
* Getters e setters
* Métodos
* `ArrayList`
* `ArrayList` de objetos
* `ArrayList<Double>`
* Estruturas de repetição
* Condicionais
* Entrada de dados com `Scanner`

## Tecnologias

* Java

## Como executar

1. Clone o repositório.
2. Abra o projeto em uma IDE compatível com Java.
3. Execute o arquivo `Main.java`.
4. Utilize o menu exibido no terminal.
